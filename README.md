# 命 InochiOS

Sistema operacional pessoal para organizar faculdade, tarefas e compromissos — um único lugar que responde "o que eu faço agora?".

> 🚧 Em desenvolvimento · Fase 0 (Requisitos) concluída · Próxima: Fase 1 (Arquitetura)

## Por quê
Tarefas, prazos da faculdade e ideias ficam espalhados entre apps, anotações e memória. O InochiOS centraliza tudo e mostra com clareza o que é prioridade.

Também é um case de portfólio: o produto é construído e orquestrado com **Claude Code**, com cada fase, decisão e checkpoint documentado em [`docs/`](docs/).

## MVP
- **Hoje** — tarefas do dia, prazos próximos e compromissos
- **Tarefas** — com data, prioridade e vínculo a matérias
- **Faculdade** — matérias, trabalhos e provas
- **Captura rápida** — anotar ideias em até dois toques

## Stack
React · TypeScript · Vite · Supabase · Vercel · PWA (mobile-first)
